🕹️ Pixel Retro Timer - Privacy Policy

Last updated: July 2026

Data Collection

Pixel Retro Timer does not collect, store, or transmit any user data to external servers.

How It Works

  • All timer data is processed locally in the browser
  • Only stores skin preference and window position in chrome.storage.local
  • No network requests, no external resources loaded
  • Sound effects are generated via Web Audio API (no audio files downloaded)

Permissions

  • activeTab: Access current tab when user clicks the extension icon
  • storage: Save skin preference, window position, and timer settings locally

Contact

For privacy concerns, contact via GitHub project page.
