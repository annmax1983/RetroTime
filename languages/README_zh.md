## 安装

1. 打开 `chrome://extensions/` 或 `edge://extensions/`
2. 开启**开发者模式**
3. 点击**加载已解压的扩展程序**，选择项目文件夹
4. 点击工具栏中的计时器图标

---

## 使用方法

1. **点击扩展图标**打开设置面板
2. **选择皮肤** — 像素、奶油、霓虹、胶片
3. **选择模式** — 秒表、倒计时、番茄钟
4. **悬浮计时器**出现在页面上 — 可任意拖拽
5. **▶ 开始 / ⏸ 暂停 / ↺ 重置** — 控制按钮
6. **⇄ 切换模式** — 在组件上直接切换
7. **🔒 锁定** — 防止误拖拽
8. **— 最小化** — 收起为标题栏

## 隐私

- 仅需 `activeTab` + `storage` 权限
- `activeTab`：用户点击扩展图标时访问当前标签页
- `storage`：本地保存皮肤偏好、窗口位置、计时设置
- 不发起网络请求 — 纯离线运行
- 不访问浏览历史、不追踪、不上传数据
- 音效通过 Web Audio API 在浏览器内生成
- [隐私政策](../privacy-policy.html)
