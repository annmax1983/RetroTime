# RetroTime — フローティングタイマーウィジェット

[English](../README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | 日本語 | [Français](README_fr.md)

ストップウォッチ、カウントダウン、ポモドーロモードを備えたミニマルなグラスモーフィズムフローティングタイマーウィジェットです。完全オフライン、データ収集ゼロ。

> Chromium系ブラウザ対応 · Manifest V3 · トラッキングなし · オフラインのみ · カスタムカラー対応

---

## RetroTimeの特長

ほとんどのタイマー拡張機能は別タブやポップアップで開きます。RetroTimeは任意のWebページ上に直接フローティング表示されます — どこにでもドラッグ、エッジにスナップ、不要時は最小化できます。

| 特長 | 詳細 |
|-----------|--------|
| ⏱️ **3つのモード** | ストップウォッチ、カスタムカウントダウン、ポモドーロ（作業＋休憩サイクル） |
| 🖱️ **ドラッグ＆スナップ** | エッジスナップと位置記憶付きのスムーズなドラッグ |
| 🔔 **アラート＆サウンド** | デスクトップ通知、ツールバーカウントダウンバッジ、3種類の組み込みサウンド（ビープ、チャイム、やさしい音）またはカスタムサウンドのアップロード |
| 📊 **履歴追跡** | 完了したタイマーを自動保存して集中セッションを追跡 |
| 🎚️ **透明度コントロール** | 20%〜100%の透明度スライダー |
| 🔒 **ロック＆最小化** | 位置をロックしてドラッグを防止、タイトルバーに最小化 |
| 🎨 **カスタムカラー** | フォント色と背景色を変更（Premium） |
| 🌍 **多言語対応** | EN、ZH、JA、DE、ES、FR |
| 🛡️ **プライバシー最優先** | データ収集なし。`storage`＋`alarms`＋`notifications`のみ |

## 無料版 vs Premium

| プラン | 機能 |
|------|----------|
| **無料版** | ストップウォッチ、カウントダウン、ポモドーロ、すべてのサウンド、透明度コントロール、ドラッグ＆スナップ、ロック＆最小化、履歴 |
| **⭐ Premium** | カスタムフォント色、カスタム背景色 |

すべてのタイマー機能は永久無料です。**カスタムカラー**（フォント色＋背景色）にはVKT Premiumライセンスが必要です — 開発を支援する買い切りライセンスです。

- 🛒 ライセンス取得：`https://www.annmax1983.com/checkout.html?plugin=retrotime`
- ⚙ 有効化：ポップアップを開き、右上の**⚙**ボタンをクリックしてライセンスキーを入力します。

> ライセンス有効化は**オプション**です。無料版はそれなしで完全に動作します。

## 使い方

1. **拡張機能アイコンをクリック**して設定を開きます
2. ヘッダーのトグルで**ウィジェットを有効化**します（初回インストール時はデフォルトでOFF）
3. **モードを選択** — ストップウォッチ、カウントダウン、ポモドーロ
4. **タイマーウィジェット**がページに表示されます — どこにでもドラッグできます
5. **▶ 開始 / ⏸ 一時停止 / ↺ リセット** — ウィジェット上の操作ボタン
6. **⇄ モード切替** — ウィジェットでモードを循環切替
7. **🔒 ロック** — 誤ドラッグを防止
8. **— 最小化** — タイトルバーのみに折りたたみ
9. **🔔 デスクトップアラート** — 時間切れ時にシステム通知（ブラウザが最小化されている場合でも動作）。ツールバーアイコンに残り時間が表示されます

## タイマーモード

| モード | 説明 |
|------|-------------|
| ⏱ **ストップウォッチ** | 00:00からカウントアップ、時間制限なし |
| ⏳ **カウントダウン** | カスタム分数を設定（10/25/30/60プリセットまたはカスタム）、00:00までカウントダウン |
| 🍅 **ポモドーロ** | カスタム作業/休憩時間（デフォルト25分/5分）、自動続行オプション、休憩スキップ |

## プライバシー

- **storage** — 設定、位置、履位置、履歴をローカルに保存
- **alarms** — 可視タブがなくても正確な時刻でタイマー完了を発火
- **notifications** — タイマー完了時にデスクトップ通知を表示
- **ライセンス（オプション）** — 有料ライセンスを有効化した場合のみ：ライセンスキーとランダムなインストール識別子＋ブラウザメタデータが`api.annmax1983.com`に送信されてライセンスの有効化/検証が行われます。タイマーデータや使用履歴が含まれることはありません。
- 無料機能でのネットワークリクエストなし — すべての処理はローカルで実行
- 効果音はWeb Audio APIでブラウザ内生成
- [プライバシーポリシー](privacy-policy.html)
