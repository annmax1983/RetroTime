# RetroTime — Floating Timer Widget

[English](../README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [日本語](README_ja.md) | [Français](README_fr.md)

A minimalist glassmorphism floating timer widget with stopwatch, countdown, and Pomodoro modes. Fully offline, zero data collection.

> Chrome / Edge / Firefox · Manifest V3 · No tracking · Offline-only · Customizable Colors

---

See the [main README](../README.md) for full documentation.

## Supported Browsers

| Browser | Status |
|--------|--------|
| Google Chrome | ✅ Fully supported |
| Microsoft Edge | ✅ Fully supported |
| Mozilla Firefox | ✅ Fully supported |
| Other Chromium-based browsers | ✅ Should work |

> **Firefox note:** Everything else behaves as on Chrome / Edge.

## Free vs Premium

| Plan | Features |
|------|----------|
| **Free** | Stopwatch, Countdown, Pomodoro, all sounds, opacity, drag, lock, history |
| **⭐ Premium** | Custom font color, custom background color |

All timer features are free forever. Custom Colors require a VKT Premium license.

> License activation is **optional**. The free tier works fully without it.
